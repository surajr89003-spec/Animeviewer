# 🎌 AnimeFit – Anime Recommendation System

## 📌 About the Project
AnimeFit is an AI-based Anime Recommendation System built using Python and Streamlit. It helps users discover anime recommendations through a simple and user-friendly interface.

## ✨ Features
- Anime recommendation system
- Anime dataset integration
- Python-based recommendation logic
- Interactive Streamlit web application
- Pickle-based anime data storage

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Pickle

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/surajr89003-spec/Animeviewer.git
```

**2. Open the project folder**

```bash
cd Animeviewer
```

**3. Install dependencies**

```bash
pip install streamlit pandas numpy
```

**4. Run the application**

```bash
streamlit run App.py
```

## 🚀 How to Use
1. Run the Streamlit application.
2. Open the application in your browser.
3. Explore the AnimeFit recommendation system.
4. Get anime recommendations.
